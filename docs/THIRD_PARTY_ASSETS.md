## Kenney investigation (evidence only; nothing here is assumed)
**What the repository proves**
- The models were added by the owner's account in three GitHub web uploads on 2026-05-10: `8b549ed` (18 files, characters), `9b31f8b` ("this is all of the vehicles and blasters for them", 79 files) and `fb0bcec` (30 files, "Add files via upload"). No archive, README or license file came with them, and none exists anywhere in the git history.
- The owner's own docs name the source: `agentic docs/ASSET_RULES.md` ("Many future assets will come from Kenney assets"), `PROJECT_CONTEXT.md`, `docs/design/*.md` ("Kenney assets are PERFECT for this game"). Code comments (`src/data/objects.ts`, `src/assets/characters.ts`, `src/render/*`) repeat the attribution. Those comments were written inside this project, so they are the project's belief, not independent proof.
- The GLB headers carry no copyright or pack name: all 126 files report only `generator: UnityGLTF`, version 2.0, no `copyright`, no extras.
- File naming is *consistent with* Kenney's published kits (this is a hypothesis from names alone): `blaster-a..r`, `bullet-foam*`, `grenade-*`, `scope-*`, `silencer-*` (a blaster/weapon kit); `sedan`, `suv`, `taxi`, `police`, `ambulance`, `firetruck`, `garbage-truck`, `delivery`, `hatchback-sports`, `race*`, `truck*`, `van`, `tractor*`, `wheel-*`, `debris-*`, `cone`, `box` (a car kit); `kart-oobi/oodi/ooli/oopi/oozi`, `vehicle-*`; `train-*`; `character-a..r` (blocky characters). Pack names and versions are **not** determinable from the repository.
- Attribution requirement: none can be stated from the repository. Kenney's pages describe their assets as CC0 (public knowledge, **not verified here**: `kenney.nl` is blocked by this environment's network policy, so the pack pages could not be read).

**What actually ships** (the rest of the 126 files are repository-only and are not in any build)
- Android and desktop bundles: 10 vehicle GLBs (`hatchback-sports`, `sedan`, `sedan-sports`, `race`, `police`, `taxi`, `ambulance`, `truck`, `truck-flat`, `vehicle-monster-truck`) and `colormap.png`.
- Baked into `src/assets/baked/zombieModels.json` at build time: the 18 `assets-source/characters/character-*.glb` and their `texture-*.png`.

**Owner-supplied evidence needed before commercial release** (exactly these files): the original download (zip with its license file, or the page URL and date) for the pack(s) containing the 10 vehicle GLBs above + `colormap.png`, and for the pack containing `character-a..r` + `texture-a..r`. The other ~98 GLBs only need evidence if they are ever shipped (`src/data/objectsCatalog.ts` lists them as unused). Once supplied, record pack name, URL, date and license text here and in `THIRD_PARTY_NOTICES.md`. Nothing was removed or replaced.
