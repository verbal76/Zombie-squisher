# DESIGN_TRUTHS.md

- The game must remain easy to understand immediately.
- Touchscreen controls are the primary input method.
- Bluetooth controllers are optional enhancements only.
- Zombie density should become overwhelming late game.
- Cars should feel progressively more powerful.
- Upgrades should feel impactful.
- Unlocking a new vehicle should feel significant.
- Gameplay is more important than realism.
- Performance is more important than graphical fidelity.
- Runs should escalate quickly into chaos.
- The game should feel satisfying even with placeholder assets.
- UI should remain readable during intense gameplay.
- Avoid unnecessary complexity during early development.
