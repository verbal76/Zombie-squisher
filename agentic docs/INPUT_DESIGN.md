# INPUT_DESIGN.md

Primary Input:
Touchscreen controls

Secondary Input:
Bluetooth controller support

Design Philosophy:
The game must always be fully playable on touch devices.
Controllers are optional enhancements.

Touchscreen Goals:
- Large readable buttons
- Responsive controls
- Minimal precision requirements
- Comfortable thumb placement
- Avoid covering important gameplay space

Controller Goals:
- Standard dual stick support
- Plug-and-play compatibility
- No controller-exclusive mechanics

Important:
Touch controls take priority over controller optimization.
