# PROJECT_CONTEXT.md

Project Name:
Zombie Crusher

Project Type:
Mobile arcade survival driving game

Target Platform:
Android phones

Input Philosophy:
Touchscreen controls are primary.
Bluetooth controller support is secondary.

Development Status:
Very early prototype.
Placeholder color blocks currently in use.
Gameplay systems are priority over visual polish.

Core Gameplay:
The player drives a vehicle while zombies approach from all directions off screen.
Zombie density increases over time.
Boss zombies eventually appear.
The player survives as long as possible while killing zombies.

Kill System:
Every zombie killed contributes to the player's total kill count.

Progression:
Kills unlock upgrades for the current vehicle.

Example Upgrades:
- speed
- durability
- mounted weapons
- ram damage
- handling

Vehicle Progression:
Each car can be upgraded multiple times.
Fully upgrading a vehicle unlocks the next vehicle.

Gameplay Feel:
Arcade style
Fast paced
Chaotic later game
Easy to understand immediately

Current Priorities:
- driving feel
- zombie spawning
- performance on Android
- upgrade systems
- kill tracking
- enemy scaling
- touch controls

Visual Direction:
Low poly stylized look.
Many assets will later come from Kenney assets.
Gameplay readability is more important than realism.

Performance Philosophy:
The game should prioritize smooth gameplay over graphical complexity.
The game should remain playable on midrange Android devices.

Build Pipeline:
GitHub for version control.
EAS for Android builds and OTA updates.

Important:
Do not overcomplicate early architecture.
Focus on gameplay systems first.
